Raphael Provider

Raphael provides free image generation via raphael.app. It supports text-to-image and image-to-image (img2img) generation with configurable aspect ratio, resolution, and quality.

Raphael models use the raphael/ prefix. The only model id is raphael/image, which maps to the upstream raphael-basic model.

from fishr import Client

client = Client()

result = client.images.generate(
    model="raphael/image",
    prompt="A cat riding a skateboard on Mars",
)

print(result.data[0].url)

Text-to-Image

Generate images from a text prompt via client.images.generate().

from fishr import Client

client = Client()

result = client.images.generate(
    model="raphael/image",
    prompt="A serene mountain lake at sunset",
    number_of_images=2,
    aspect="1:1",
    resolution="0.5k",
    quality="low",
)

for img in result.data:
    print(img.url)

The response is an ImageResponse with data containing one ImageUrl per generated image. URLs are absolute (https://raphael.app/api/proxy-image/<uuid>.webp).

Image-to-Image (img2img)

Pass an image dict to transform an existing image. The image must be base64-encoded with a supported MIME type (image/webp, image/png, image/jpeg, or image/jpg).

import base64
from fishr import Client

client = Client()

with open("input.webp", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

result = client.images.generate(
    model="raphael/image",
    prompt="Make it to be black & red",
    image={
        "mime_type": "image/webp",
        "base64_data": encoded,
    },
    aspect="auto",
    resolution="1k",
    quality="low",
)

print(result.data[0].url)
ℹ img2img requires a reference image. When image is provided, the upstream request is sent with action: "img2img" and the image embedded as a data: URI in input_image and input_image_list.

Parameters

ParameterTypeDefaultDescription
modelstr"raphael/image"Model id. Only raphael/image is supported.
promptstr—Text prompt describing the image to generate.
number_of_imagesint1Number of images to generate (1+).
aspectstr"1:1"Aspect ratio: 1:1, 4:3, 3:4, 16:9, 9:16, or auto.
resolutionstr"0.5k"Resolution: 0.5k, 1k, or 2k.
qualitystr"low"Quality: low, medium, or high.
fast_modeboolFalseUse fast generation mode.
high_qualityboolFalseRequest high-quality output.
imagedict | NoneNoneReference image for img2img. {"mime_type": ..., "base64_data": ...}.
ℹ Invalid values fall back to defaults. An unknown aspect, resolution, or quality silently falls back to "1:1", "0.5k", and "low" respectively.

from fishr import AsyncClient

client = AsyncClient()

result = await client.images.generate(

Direct Usage

You can use the Raphael provider directly without the high-level client.

from fishr import Raphael

r = Raphael()

# text-to-image
result = r.generate("A cat riding a skateboard")
print(result.images)

# image-to-image
import base64
with open("input.webp", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

result = r.generate(
    "Make it to be black & red",
    image={"mime_type": "image/webp", "base64_data": encoded},
    aspect="auto",
    resolution="1k",
)
print(result.images)

Limitations

  • Raphael is a reverse-engineered public endpoint — it may break if the upstream service changes.
  • The endpoint is protected by Cloudflare. Requests use a Chrome-impersonating HTTP client (primp) to bypass it; a valid cf_clearance cookie is not required for the API path.
  • Only raphael-basic is available. Other upstream model ids (raphael-pro, etc.) are not exposed.
  • No streaming. Image generation is a single request that returns NDJSON with one JSON object per image.
  • Upstream failures return an empty result (no exception). Check len(result.data) or len(result.images) to detect failures.
  • Rate limits may apply. Avoid rapid sequential requests.
  • Image input for img2img must be base64-encoded webp, png, jpeg, or jpg. Other formats are silently ignored and the request falls back to text-to-image.
