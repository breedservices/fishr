Telnyx TTS Provider

Telnyx TTS is a free text-to-speech provider backed by the public telnyx.com/api/tts-demo no-auth fast-path demo endpoint. It serves the Telnyx.NaturalHD Rime Arcana voice set. No API key, no signup, no email required.

Telnyx TTS models use the telnyx-tts/ prefix. Each model id is a voice: telnyx-tts/astra routes to Telnyx.NaturalHD.astra upstream. The response model field always reports Telnyx.NaturalHD so you know what actually ran.

from fishr import Client

client = Client()

result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Hello from fishr.",
)

# result.data[0].audio is raw MP3 bytes
with open("out.mp3", "wb") as fh:
    fh.write(result.data[0].audio)

ℹ Model = voice. Unlike fm/*, there is no separate style layer — every telnyx-tts/* id is a voice. You can still override the voice on top of any model with voice="...". 
from fishr import Client

client = Client()

# default voice (astra)
result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Hello from astra.",
)

# different voice via model
result = client.audio.speech.create(
    model="telnyx-tts/luna",
    input="Hello from luna.",
)

# override the voice on top of any model
result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Hello from orion via override.",
    voice="orion",
)

Formats & Transcoding

The demo endpoint only emits MP3. fishr can transcode the response to other container/codec formats using the bundled static-ffmpeg binary — no system ffmpeg install required. Pass format=... to speech.create:

formatMIMECodec
mp3audio/mpeglibmp3lame
oggaudio/ogglibvorbis
wavaudio/wavpcm_s16le
flacaudio/flacflac
opusaudio/opuslibopus
aacaudio/aacaac
m4aaudio/mp4aac
 
from fishr import Client

client = Client()

# MP3 (default — no transcoding)
result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="MP3 by default.",
)

# WAV (transcoded from MP3)
result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Transcode me to WAV.",
    format="wav",
)
print(result.data[0].mime_type)  # audio/wav

# OGG Vorbis (transcoded from MP3)
result = client.audio.speech.create(
    model="telnyx-tts/luna",
    input="Transcode me to OGG.",
    format="ogg",
)
print(result.data[0].mime_type)  # audio/ogg
ℹ The bundled ffmpeg binary is fetched on first transcode. static-ffmpeg downloads the platform binary once and caches it; subsequent calls reuse the cached executable. Transcoding is lazy — if you only ever request MP3, the binary is never loaded.

Client Usage

The high-level client.audio.speech.create(...) API mirrors the OpenAI text-to-speech surface. It returns an AudioResponse with a single AudioData item in data.

from fishr import Client

client = Client()

result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Hello from the high level client.",
)

item = result.data[0]
print(item.voice)      # Telnyx.NaturalHD.astra
print(item.model)      # Telnyx.NaturalHD
print(item.mime_type)  # audio/mpeg
print(len(item.audio)) # byte count

with open("out.mp3", "wb") as fh:
    fh.write(item.audio)

Direct Usage

You can use the Telnyx TTS provider directly without the Client. The low-level TelnyxAudio.speak() returns raw MP3 bytes — it does not transcode. Use the high-level client if you need format=.

from fishr import TelnyxAudio

ta = TelnyxAudio()

# default model is telnyx-tts/astra
result = ta.speak("Hello world.")
print(result.model, result.voice, len(result.audio))

# pick a voice by model
result = ta.speak("Hello from luna.", model="telnyx-tts/luna")

# override voice on top of any model
result = ta.speak("Hello from orion.", model="telnyx-tts/astra", voice="orion")

# pass an explicit BCP-47 language code (defaults to en-US)
result = ta.speak("Bonjour.", model="telnyx-tts/astra", language="fr-FR")

ta = TelnyxAudio()
result = await ta.speak_async("Hello from async.", model="telnyx-tts/nova")
print(result.voice, len(result.audio))

Streaming

Pass stream=True to ta.speak(...) for an async iterator over the raw audio bytes. The whole response is fetched first (the upstream API does not expose chunked reads), then yielded.

import asyncio
from fishr import TelnyxAudio

async def main():
    ta = TelnyxAudio()
    stream = ta.speak("Streaming this out.", model="telnyx-tts/astra", stream=True)
    collected = b""
    async for chunk in stream:
        collected += chunk
    print(len(collected))

asyncio.run(main())

Limitations

  • Telnyx TTS uses the public fast-path demo endpoint — no API key required, but rate-limited (try to keep request volume modest).
  • There is no uptime guarantee. Availability depends on the upstream demo service.
  • Only the Telnyx.NaturalHD voice set is exposed on the demo endpoint. Other Telnyx TTS tiers (Natural, KokoroTTS, Qwen3TTS, Ultra, Grok) are documented by Telnyx but reject every voice on the no-auth demo endpoint, so they are not exposed by fishr.
  • The demo endpoint requires a non-empty language string. fishr defaults to en-US when you do not pass one.
  • The demo endpoint only emits MP3. Other formats are transcoded from MP3 via static-ffmpeg.
  • Upstream failures (rate limits, invalid voices, network errors) are logged as warnings and return empty audio rather than raising — long-running scripts will not crash on a 429 or 400.
  • Five voices are available: telnyx-tts/astra, telnyx-tts/luna, telnyx-tts/sol, telnyx-tts/nova, telnyx-tts/orion.
  • Unknown telnyx-tts/<x> ids are passed through to the upstream (which will 400 and return empty audio) so the upstream stays the source of truth for the voice catalogue.
