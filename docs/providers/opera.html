Opera Aria Provider

Opera Aria provides free access to an AI chat model through Opera's API. It supports streaming, system messages, conversation history, and a unique think harder mode for more thoughtful responses.

Opera Aria models use the opera/ prefix.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="opera/aria",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.text)

Streaming

Set stream=True to receive chunks as they arrive.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="opera/aria",
    messages=[{"role": "user", "content": "Count from 1 to 5"}],
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

Think Harder

Opera Aria supports a think harder mode that prompts the model to reason more deeply before responding. This is useful for complex questions that require step-by-step thinking. Pass think_harder=True to enable it.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="opera/aria",
    messages=[{"role": "user", "content": "What is 17 * 23?"}],
    think_harder=True,
)
print(response.text)
ℹ Opera Aria only. The think_harder parameter is specific to the Opera Aria provider. It has no effect on other providers.

System Messages

Opera Aria supports system messages to set the model's behavior and persona.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="opera/aria",
    messages=[
        {"role": "system", "content": "You are a robot. Always respond like a robot."},
        {"role": "user", "content": "Say hello."},
    ],
)
print(response.text)

Conversation History

Opera Aria supports conversation history. The full message history is sent with each request so the model has context from previous turns.

from fishr import Client

client = Client()
conv = client.conversation(model="opera/aria")

conv.system("You are a helpful assistant. Be brief.")
conv.ask("Remember the number 55.")
reply = conv.ask("What number did I tell you to remember?")
print(reply)

conv.clear()  # reset history
ℹ Context windows vary by model. Very long conversations may lose earlier context as the history exceeds the model's context limit. Use conv.clear() to reset when needed.

Direct Usage

You can use the Opera Aria provider directly without going through the Client.

from fishr import OperaAria

opera = OperaAria()

# Simple ask
result = opera.ask("Say hello in one word.")
print(result.content)

# Chat with messages
result = opera.chat([
    {"role": "system", "content": "Be concise."},
    {"role": "user", "content": "What is 2+2?"},
])
print(result.content)

# Streaming
stream = opera.chat(
    [{"role": "user", "content": "Count to 5"}],
    stream=True,
)
for chunk in stream:
    print(chunk, end="")

Starting a new conversation

Use new_chat() to reset the conversation state and start fresh.

from fishr import OperaAria

opera = OperaAria()

result = opera.ask("Hello!")
print(result.content)

# Start a new, unrelated conversation
opera.new_chat()
result = opera.ask("What is Python?")
print(result.content)

Limitations

  • Opera Aria uses a reverse-engineered API with anonymous authentication — it may break if the upstream service changes.
  • There is no uptime guarantee. Availability depends on the upstream service.
  • No web search — Opera Aria does not support live web search.
  • Think harder mode is only available via the direct OperaAria provider, not through Client.chat.completions.create().
  • Rate limits may apply. Avoid rapid sequential requests.
  • Authentication tokens are generated on-the-fly and may occasionally fail — retries are recommended.
