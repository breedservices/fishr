Noxus Provider

Noxus provides free access to 8 models through a reverse-engineered API. It supports web search, image input, streaming, and conversation history.

All Noxus models are specified with the noxus/ prefix — or omit it, as it's the default.

from fishr import Client

client = Client()

# these are equivalent
response = client.chat.completions.create(
    model="noxus/openai",
    messages=[{"role": "user", "content": "Hello!"}],
)

response = client.chat.completions.create(
    model="openai",
    messages=[{"role": "user", "content": "Hello!"}],
)

Web Search

6 out of 8 Noxus models support live web search. Pass web_search=True to enable it.

ModelWeb Search
noxus/openai✅
noxus/google✅
noxus/sonnet-4.6✅
noxus/sonnet-3.5✅
noxus/grok-4.3✅
noxus/perplexity❌

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="noxus/grok-4.3",
    messages=[{"role": "user", "content": "Latest news on SpaceX"}],
    web_search=True,
)

print(response.text)
⚠ Web search is not supported by all models. Passing web_search=True to noxus/perplexity or noxus/metaai will have no effect.

Image Input

5 out of 8 Noxus models accept image attachments. Attach images to messages using the image key with mime_type and base64_data.

ModelImage Input
noxus/openai✅
noxus/google✅
noxus/sonnet-4.6❌
noxus/sonnet-3.5✅
noxus/grok-4.3✅
noxus/perplexity✅
noxus/metaai❌
noxus/qwen❌
 
import base64
from fishr import Client

client = Client()

# read an image file and encode it
with open("photo.png", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="noxus/openai",
    messages=[{
        "role": "user",
        "content": "What is in this image?",
        "image": {
            "mime_type": "image/png",
            "base64_data": encoded,
        },
    }],
)

print(response.text)
⚠ Image input is not supported by all models. Models marked with ❌ will ignore attached images. Noxus does not support image generation — use DeepAI for that.

Conversation History

All Noxus models support conversation history. The full message history is sent with each request so the model has context from previous turns.

ℹ Context windows vary by model. Very long conversations may lose earlier context as the history exceeds the model's context limit. Use conv.clear() to reset when needed. 
from fishr import Client

client = Client()
conv = client.conversation(model="noxus/openai")

conv.system("You are a helpful assistant.")
conv.ask("Remember: 42")
reply = conv.ask("What number did I say?")
print(reply)  # "You said 42."

conv.clear()  # reset history

Limitations

  • Noxus is a reverse-engineered API — it may break if the upstream service changes.
  • There is no uptime guarantee. Availability depends on the upstream service.
  • Rate limits may apply. Avoid rapid sequential requests.
  • Image input is not supported by noxus/sonnet-4.6, noxus/metaai, and noxus/qwen.
  • Web search is not supported by noxus/perplexity and noxus/metaai.
  • Image generation is not available. Use DeepAI's deepai/image model instead.
  • Streaming may occasionally drop chunks or include partial data on slow connections.
