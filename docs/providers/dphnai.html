DphnAI Provider

DphnAI provides free access to 2 Dolphin models through a reverse-engineered API. It supports streaming, conversation history, and configurable templates.

DphnAI models use the dphnai/ prefix.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="dphnai/6b",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.text)

Templates

DphnAI supports configurable templates that adjust the model's behavior and tone. Templates are passed as the template keyword argument.

TemplateDescription
logicalLogical and analytical responses
creativeCreative and imaginative responses
summarizeSummarization-focused responses
code-beginnerBeginner-friendly coding help with step-by-step explanations
code-advancedAdvanced coding assistance for experienced developers
 
from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="dphnai/6b",
    messages=[{"role": "user", "content": "How do I write a for loop in Python?"}],
    template="code-beginner",
)
print(response.text)
ℹ Templates are optional. If no template is specified, the model uses its default behavior. Templates only affect the model's response style — they don't change the underlying model.

Streaming

Set stream=True to receive chunks as they arrive. DphnAI uses standard OpenAI-compatible SSE format.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="dphnai/6b",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

Conversation History

DphnAI supports conversation history. The full message history is sent with each request so the model has context from previous turns.

from fishr import Client

client = Client()
conv = client.conversation(model="dphnai/6b")

conv.system("You are a helpful assistant.")
conv.ask("Remember: 42")
reply = conv.ask("What number did I say?")
print(reply)

conv.clear()  # reset history
ℹ Context windows vary by model. The 6b model has a smaller context window (~1000 tokens) while the 24b model can handle more. Very long conversations may lose earlier context.

Limitations

  • DphnAI is a reverse-engineered API — it may break if the upstream service changes.
  • There is no uptime guarantee. Availability depends on the upstream service.
  • No image support — neither image input nor image generation is available.
  • No web search — none of the DphnAI models support web search.
  • Small models — the largest model is 24B parameters, which is smaller than most other providers' models. Quality may be lower for complex tasks.
  • Rate limits may apply. Avoid rapid sequential requests.
