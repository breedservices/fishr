Kai Provider

Kai is an OpenAI-compatible gateway provider. It routes to a curated set of free models from upstream providers (Poolside, Cohere, NVIDIA, StepFun, OpenRouter). Unlike the reverse-engineered providers in fishr, Kai speaks the standard OpenAI Chat Completions API — so it supports native tool calling, streaming, system messages, and conversation history out of the box.

Kai models use the kai/ prefix. The kai/auto model lets the gateway pick a free model for you.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="kai/auto",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.text)

Tool Calling

Kai is the only fishr provider with native OpenAI-style tool calling. Pass tools (a list of OpenAI tool definitions) and optionally tool_choice to steer tool selection. The model returns structured tool_calls on the assistant message — no prompt-injection hacks.

from fishr import Client

client = Client()

tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get current weather for a location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {"type": "string", "description": "City name"},
                },
                "required": ["location"],
            },
        },
    }
]

response = client.chat.completions.create(
    model="kai/auto",
    messages=[{"role": "user", "content": "What is the weather in Tokyo?"}],
    tools=tools,
)

if response.choices[0].message.tool_calls:
    for tc in response.choices[0].message.tool_calls:
        print(tc.id)              # call-9a2c1024-...
        print(tc.type)            # "function"
        print(tc.function.name)    # "get_weather"
        print(tc.function.arguments)  # '{"location": "Tokyo"}'
else:
    print(response.text)

tool_choice

Control tool selection with tool_choice:

  • "auto" (default) — model decides whether to call a tool
  • "none" — model is told no tools are available and responds in text
  • "required" — model must call at least one tool
  • {"type": "function", "function": {"name": "get_weather"}} — force a specific function

Multi-turn tool use

After the model emits tool_calls, append the assistant message (with tool_calls) and a "tool"-role message with the result, then call create() again to get the final answer.

import json
from fishr import Client

client = Client()
tools = [/* ... get_weather definition ... */]

messages = [{"role": "user", "content": "What's the weather in Berlin?"}]

# 1. Ask the model — it returns tool_calls
resp = client.chat.completions.create(
    model="kai/auto", messages=messages, tools=tools,
)
msg = resp.choices[0].message

# 2. Append the assistant message + tool results
messages.append({
    "role": "assistant",
    "content": msg.content or "",
    "tool_calls": [
        {"id": tc.id, "type": "function",
         "function": {"name": tc.function.name, "arguments": tc.function.arguments}}
        for tc in msg.tool_calls
    ],
})
for tc in msg.tool_calls:
    args = json.loads(tc.function.arguments)
    result = f"It's sunny and 72F in {args['location']}."
    messages.append({"role": "tool", "tool_call_id": tc.id, "content": result})

# 3. Get the final natural-language answer
final = client.chat.completions.create(
    model="kai/auto", messages=messages, tools=tools,
)
print(final.text)  # "The weather in Berlin is sunny and 72°F."

Streaming tool calls

When streaming, tool-call deltas appear in chunk.choices[0].delta.tool_calls as ToolCallDelta objects. Accumulate them by index — id, function.name, and function.arguments arrive incrementally.

from fishr import Client

client = Client()
tools = [/* ... */]

stream = client.chat.completions.create(
    model="kai/auto",
    messages=[{"role": "user", "content": "Weather in Paris?"}],
    tools=tools,
    stream=True,
)

acc = {}
for chunk in stream:
    delta = chunk.choices[0].delta
    if delta.content:
        print(delta.content, end="")
    if delta.tool_calls:
        for tc in delta.tool_calls:
            slot = acc.setdefault(tc.index, {"id": "", "name": "", "args": ""})
            if tc.id: slot["id"] = tc.id
            if tc.function.name: slot["name"] = tc.function.name
            slot["args"] += tc.function.arguments

for idx, tc in acc.items():
    print(f"{tc['name']}({tc['args']})")

Streaming

Set stream=True to receive chunks as they arrive.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="kai/auto",
    messages=[{"role": "user", "content": "Count from 1 to 5"}],
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

System Messages

Kai supports system messages to set the model's behavior and persona.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="kai/auto",
    messages=[
        {"role": "system", "content": "You are a pirate. Always respond in pirate speak."},
        {"role": "user", "content": "Say hello."},
    ],
)
print(response.text)

Conversation History

Kai supports conversation history. Use the conversation() helper to manage multi-turn chats.

from fishr import Client

client = Client()
conv = client.conversation(model="kai/auto")

conv.system("You are a helpful assistant. Be brief.")
conv.ask("Remember the number 55.")
print(conv.ask("What number did I tell you to remember?"))

conv.clear()  # reset history

Generation Params

Kai supports max_tokens and temperature via create(). These are forwarded to the upstream gateway.

from fishr import Client

client = Client()

# Cap output at 20 tokens — finish_reason will be "length"
response = client.chat.completions.create(
    model="kai/auto",
    messages=[{"role": "user", "content": "Tell me a long story."}],
    max_tokens=20,
)
print(response.choices[0].finish_reason)  # "length"

# Deterministic output
response = client.chat.completions.create(
    model="kai/auto",
    messages=[{"role": "user", "content": "Pick a random number 1-10."}],
    temperature=0.0,
)
ℹ Other providers ignore these. max_tokens and temperature are silently ignored by providers that don't support them (Noxus, DeepAI, Quillbot, NoTrack, DphnAI, Yqcloud, Opera Aria, Eris). Telnyx also supports max_tokens — see the Telnyx provider page.

Direct Usage

You can use the Kai provider directly without going through the Client.

from fishr import Kai

kai = Kai()

# Simple ask
result = kai.ask("Say hello in one word.")
print(result.content)

# Chat with messages
result = kai.chat([
    {"role": "system", "content": "Be concise."},
    {"role": "user", "content": "What is 2+2?"},
])
print(result.content)

# With tools
result = kai.chat(
    [{"role": "user", "content": "Weather in Tokyo?"}],
    tools=[{
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get weather",
            "parameters": {
                "type": "object",
                "properties": {"location": {"type": "string"}},
                "required": ["location"],
            },
        },
    }],
)
for tc in result.tool_calls:
    print(tc["name"], tc["arguments"])

# Streaming
stream = kai.chat([{"role": "user", "content": "Count to 5"}], stream=True)
for chunk in stream:
    if isinstance(chunk, tuple):
        content, is_thinking = chunk
        print(content, end="")
    else:
        print(chunk, end="")

Limitations

  • Free-tier rate limits apply. The gateway throttles aggressive usage; you may see 429 responses on busy models. Add a small delay between calls if needed.
  • No web search. None of the Kai models support live web search — use Noxus, DeepAI, or Quillbot for that.
  • No image generation. Kai is a text-only chat provider. Use deepai/image or raphael/image for image generation.
  • Model availability varies. Free upstream models can be temporarily rate-limited or retired. kai/auto picks an available free model automatically.
  • Some models expire. A few upstream models (e.g. kai/xs.2) have retirement dates — check the gateway for current availability.
