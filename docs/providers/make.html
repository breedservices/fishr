Make Provider

Make is a text-to-speech provider offering 39 voices via a Qwen3 TTS endpoint. It mirrors the OpenAI audio.speech.create API surface and returns raw WAV audio bytes. No API key required.

Make models use the make/ prefix. Each model id is a voice — pick one and pass text to create(). 

from fishr import Client

client = Client()

result = client.audio.speech.create(
    model="make/aura",
    input="Hello from fishr.",
)

# result.data[0].audio is raw WAV bytes
with open("out.wav", "wb") as fh:
    fh.write(result.data[0].audio)

Client Usage

Use client.audio.speech.create() with a make/* model. The voice parameter overrides the model's voice. 

from fishr import Client

client = Client()

# default voice (aura)
result = client.audio.speech.create(
    model="make/aura",
    input="Hello world.",
)
print(result.data[0].voice)  # "aura"

# different voice via model
result = client.audio.speech.create(
    model="make/breeze",
    input="Hello from breeze.",
)

# override voice on top of any model
result = client.audio.speech.create(
    model="make/aura",
    input="Hello from mist via override.",
    voice="mist",
)

Formats & Transcoding

Make emits WAV natively. Pass format=... to client.audio.speech.create() to transcode to any of these containers using the bundled static-ffmpeg binary — no system ffmpeg install needed:

  • mp3 — MPEG-1 Audio Layer III (audio/mpeg)
  • ogg — Ogg Vorbis (audio/ogg)
  • wav — PCM 16-bit (audio/wav) — native, no transcoding
  • flac — Free Lossless Audio (audio/flac)
  • opus — Opus in Ogg (audio/opus)
  • aac — Advanced Audio Coding (audio/aac)
  • m4a — AAC in MP4 container (audio/mp4)

The mime_type on the returned AudioData reflects the output format. 

from fishr import Client

client = Client()

# native WAV (no transcoding)
result = client.audio.speech.create(
    model="make/aura",
    input="Native WAV.",
)
print(result.data[0].mime_type)  # audio/wav

# transcode WAV -> MP3
result = client.audio.speech.create(
    model="make/aura",
    input="Transcode me to MP3.",
    format="mp3",
)
print(result.data[0].mime_type)  # audio/mpeg

# transcode WAV -> Opus
result = client.audio.speech.create(
    model="make/breeze",
    input="Transcode me to Opus.",
    format="opus",
)
print(result.data[0].mime_type)  # audio/opus
ℹ Direct MusicMake.speak() always returns WAV. Transcoding is only available through the high-level client.audio.speech.create() with format=....

Direct Usage

You can use the Make provider directly without the Client wrapper. The low-level speak() method returns raw WAV bytes — use the high-level client if you need format= transcoding. 

from fishr import MusicMake

mm = MusicMake()

# default voice (aura)
result = mm.speak("Hello world.")
print(result.voice, len(result.audio))

# explicit voice
result = mm.speak("Hello from breeze.", model="make/breeze")
print(result.voice, len(result.audio))

# streaming
stream = mm.speak("Hello from mist.", model="make/mist", stream=True)
async for chunk in stream:
    ...

Async

Use AsyncClient or speak_async for coroutine-based workflows. 

from fishr import AsyncClient

client = AsyncClient()

result = await client.audio.speech.create(
    model="make/mist",
    input="Hello from the async client.",
)
print(result.data[0].voice)

Limitations

  • Make uses a reverse-engineered API — it may break if the upstream service changes.
  • There is no uptime guarantee. Availability depends on the upstream service.
  • WAV only by default — use format=... with the high-level client to transcode.
  • No instructions/styles — unlike fm/*, Make does not support voice styling or prompt-based instructions.
  • Rate limits may apply on the upstream endpoint.
