Telnyx Provider

Telnyx provides free access to four chat models via the public telnyx.com/api/inference fast-path demo endpoint. It supports streaming, system messages, conversation history, and a thinking mode that surfaces the model's reasoning process. No API key, no signup, no email required.

Telnyx models use the telnyx/ prefix.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="telnyx/glm-5.1",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.text)

Streaming

Set stream=True to receive chunks as they arrive.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="telnyx/glm-5.1",
    messages=[{"role": "user", "content": "Count from 1 to 5"}],
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

Think Harder

Telnyx supports a thinking mode via think_harder=True (mapped to enable_thinking on the upstream). When streaming, reasoning tokens appear in chunk.choices[0].delta.thinking.

from fishr import Client

client = Client()

# Non-streaming — reasoning is captured separately
response = client.chat.completions.create(
    model="telnyx/glm-5.1",
    messages=[{"role": "user", "content": "What is 17 * 23?"}],
    think_harder=True,
)
print(response.text)

Streaming with thinking

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="telnyx/glm-5.1",
    messages=[{"role": "user", "content": "What is 17 * 23?"}],
    stream=True,
    think_harder=True,
)

for chunk in response:
    if chunk.choices[0].delta.thinking:
        print(chunk.choices[0].delta.thinking, end="", flush=True)
    elif chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)

System Messages

Telnyx supports system messages to set the model's behavior and persona.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="telnyx/glm-5.1",
    messages=[
        {"role": "system", "content": "You are a pirate. Always respond in pirate speak."},
        {"role": "user", "content": "Say hello."},
    ],
)
print(response.text)

Max Tokens

Telnyx supports max_tokens via create(). If omitted, it defaults to the model's context cap:

  • telnyx/glm-5.2 — 968,000
  • telnyx/glm-5.1 — 168,000
  • telnyx/kimi-k2.6 — 224,000
  • telnyx/minimax-m3 — 168,000
from fishr import Client

client = Client()

# Cap output at 100 tokens
response = client.chat.completions.create(
    model="telnyx/glm-5.2",
    messages=[{"role": "user", "content": "Tell me a long story."}],
    max_tokens=100,
)
print(response.choices[0].finish_reason)  # "length" if truncated

Conversation History

Telnyx supports conversation history. The full message history is sent with each request so the model has context from previous turns.

from fishr import Client

client = Client()
conv = client.conversation(model="telnyx/glm-5.1")

conv.system("You are a helpful assistant. Be brief.")
conv.ask("Remember the number 55.")
reply = conv.ask("What number did I tell you to remember?")
print(reply)

conv.clear()  # reset history
ℹ Context windows vary by model. Very long conversations may lose earlier context as the history exceeds the model's context limit. Use conv.clear() to reset when needed.

Direct Usage

You can use the Telnyx provider directly without going through the Client.

from fishr import Telnyx

tx = Telnyx()

# Simple ask
result = tx.ask("Say hello in one word.")
print(result.content)

# Chat with messages
result = tx.chat([
    {"role": "system", "content": "Be concise."},
    {"role": "user", "content": "What is 2+2?"},
])
print(result.content)

# Streaming
stream = tx.chat(
    [{"role": "user", "content": "Count to 5"}],
    stream=True,
)
for chunk in stream:
    if isinstance(chunk, tuple):
        content, is_thinking = chunk
        if is_thinking:
            print(f"[think] {content}", end="")
        else:
            print(content, end="")
    else:
        print(chunk, end="")

With thinking enabled

from fishr import Telnyx

tx = Telnyx()

# Enable reasoning mode
result = tx.ask("Explain quantum entanglement.", enable_thinking=True)
print(result.content)
print(result.thinking)

Async

Use AsyncClient or ask_async / chat_async for coroutine-based workflows.

import asyncio
from fishr import AsyncClient

async def main():
    client = AsyncClient()
    response = await client.chat.completions.create(
        model="telnyx/glm-5.1",
        messages=[{"role": "user", "content": "Hello!"}],
    )
    print(response.text)

asyncio.run(main())

Limitations

  • Telnyx uses the public fast-path demo endpoint — no API key required, but rate-limited to 10 requests/minute per IP.
  • There is no uptime guarantee. Availability depends on the upstream demo service.
  • No web search — Telnyx does not support live web search.
  • No image input — Telnyx does not support image attachments or image generation.
  • Upstream failures (rate limits, network errors) are logged as warnings and return empty content rather than raising — long-running scripts will not crash on a 429.
  • Four chat models are currently available: telnyx/glm-5.2, telnyx/glm-5.1, telnyx/kimi-k2.6, and telnyx/minimax-m3.
  • Telnyx also exposes a no-auth TTS demo endpoint — see Telnyx TTS for text-to-speech via the telnyx-tts/ prefix.
