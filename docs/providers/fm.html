FM Provider (OpenAI.fm)

FM is a free text-to-speech provider backed by OpenAI.fm. It mirrors the OpenAI audio.speech.create API surface, returning raw audio bytes you can save, stream, or transcode. Eleven voices and six preset styles are available.

FM models use the fm/ prefix. A model name is either a voice (e.g. fm/coral) or a style (e.g. fm/cowboy); a style sets the instructions for you and falls back to the default voice.

from fishr import Client

client = Client()

result = client.audio.speech.create(
    model="fm/coral",
    input="Hello from fishr.",
)

# result.data[0].audio is raw MP3 bytes
with open("out.mp3", "wb") as fh:
    fh.write(result.data[0].audio)

Styles

A style is a preset instructions prompt. Using a style model fills in instructions automatically and uses the default voice (coral) unless you pass voice=... explicitly.

Model Style

ℹ Voice vs. style. A voice model name only selects the voice. A style model name only selects the instructions. You can mix and match by passing model="fm/cowboy" together with voice="nova".

Instructions

The instructions parameter steers how the voice speaks — tone, pacing, pronunciation, pauses, emotion. It accepts free text. The six styles are just pre-written instructions.

from fishr import Client

client = Client()

result = client.audio.speech.create(
    model="fm/coral",
    input="The package went missing at midnight.",
    instructions="Speak slowly, with dramatic pauses. A noir detective vibe.",
)

with open("detective.mp3", "wb") as fh:
    fh.write(result.data[0].audio)
from fishr import Client

client = Client()

# style model — instructions come from the style
result = client.audio.speech.create(
    model="fm/cowboy",
    input="Howdy partner.",
)

# style model + explicit voice override
result = client.audio.speech.create(
    model="fm/cowboy",
    input="Howdy partner.",
    voice="nova",
)

Formats & Transcoding

OpenAI.fm only emits MP3. fishr can transcode the response to other container/codec formats using the bundled static-ffmpeg binary — no system ffmpeg install required. Pass format=... to speech.create:

formatMIMECodec
mp3audio/mpeglibmp3lame
oggaudio/ogglibvorbis
wavaudio/wavpcm_s16le
flacaudio/flacflac
opusaudio/opuslibopus
aacaudio/aacaac
m4aaudio/mp4aac
 
from fishr import Client

client = Client()

# MP3 (default — no transcoding)
result = client.audio.speech.create(
    model="fm/coral",
    input="MP3 by default.",
)

# OGG Vorbis (transcoded from MP3)
result = client.audio.speech.create(
    model="fm/coral",
    input="Transcode me to OGG.",
    format="ogg",
)
print(result.data[0].mime_type)  # audio/ogg

# WAV (transcoded from MP3)
result = client.audio.speech.create(
    model="fm/coral",
    input="Transcode me to WAV.",
    format="wav",
)
print(result.data[0].mime_type)  # audio/wav
ℹ The bundled ffmpeg binary is fetched on first transcode. static-ffmpeg downloads the platform binary once and caches it; subsequent calls reuse the cached executable. Transcoding is lazy — if you only ever request MP3, the binary is never loaded.

Client Usage

The high-level client.audio.speech.create(...) API mirrors the OpenAI text-to-speech surface. It returns an AudioResponse with a single AudioData item in data.

from fishr import Client

client = Client()

result = client.audio.speech.create(
    model="fm/coral",
    input="Hello from the high level client.",
    voice="coral",
)

item = result.data[0]
print(item.voice)      # coral
print(item.model)      # coral
print(item.mime_type)  # audio/mpeg
print(len(item.audio)) # byte count

with open("out.mp3", "wb") as fh:
    fh.write(item.audio)

Direct Usage

You can use the FM provider directly without the Client.

from fishr import OpenAIFM

fm = OpenAIFM()

# default voice (coral)
result = fm.speak("Hello world.")
print(result.voice, len(result.audio))

# explicit voice
result = fm.speak("Hello from nova.", voice="nova")

# style model (instructions come from the style)
result = fm.speak("Howdy partner.", model="fm/cowboy")

# custom instructions
result = fm.speak(
    "Hello world.",
    voice="sage",
    instructions="Speak softly and slowly.",
)

Async

from fishr import AsyncClient

client = AsyncClient()

result = await client.audio.speech.create(
    model="fm/coral",
    input="Hello from the async high level client.",
    voice="onyx",
)
print(result.data[0].voice)
from fishr import OpenAIFM

fm = OpenAIFM()
result = await fm.speak_async("Hello from async.", voice="sage")
print(result.voice, len(result.audio))

Streaming

Pass stream=True to fm.speak(...) for an async iterator over the raw audio bytes. The whole response is fetched first (the upstream API does not expose chunked reads), then yielded.

import asyncio
from fishr import OpenAIFM

async def main():
    fm = OpenAIFM()
    stream = fm.speak("Streaming this out.", voice="echo", stream=True)
    collected = b""
    async for chunk in stream:
        collected += chunk
    print(len(collected))

asyncio.run(main())

Limitations

  • FM uses a reverse-engineered API — it may break if OpenAI.fm changes.
  • There is no uptime guarantee. Availability depends on the upstream service.
  • OpenAI.fm only emits MP3. Other formats are transcoded from MP3 via static-ffmpeg.
  • Rate limits may apply. Avoid rapid sequential requests.
  • Streaming fetches the full response before yielding — there is no real chunked upstream stream.
  • Eleven voices and six styles are available; unknown voices are passed through to the upstream API (which may reject them).
