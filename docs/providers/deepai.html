DeepAI Provider

DeepAI provides free access to chat models and image generation through a public API. It supports streaming, web search, and multiple models including online search.

DeepAI models use the deepai/ prefix.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="deepai/standard",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.text)

Web Search

Only deepai/online supports web search. For other models, you can pass web_search=True and it will automatically use the online model.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="deepai/online",
    messages=[{"role": "user", "content": "What happened in tech today?"}],
    web_search=True,
)

print(response.text)

Image Generation

DeepAI supports two ways to generate images:

Direct image generation

Use client.images.generate() with deepai/image for direct text-to-image generation. The response contains the image URL.

from fishr import Client

client = Client()

result = client.images.generate(
    model="deepai/image",
    prompt="A cat riding a skateboard on Mars",
)

# the generated image URL
print(result.data[0].url)

Via completions API

You can also use deepai/image through the completions API for direct text-to-image generation. All DeepAI chat models can also trigger inline image generation during conversation via the built-in image generator tool.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="deepai/image",
    messages=[{"role": "user", "content": "A cat riding a skateboard"}],
)
print(response.text)  # image URL
ℹ Image generation mode. When using deepai/image via client.images.generate(), the model bypasses chat entirely and returns a direct image generation result. When using chat models, image generation is triggered by the model itself during conversation.

Image Upload

DeepAI chat models support uploading images as attachments. Include a base64-encoded image in the image key of a message. The image is automatically uploaded to DeepAI's attachment API and referenced by UUID in the conversation.

ℹ Image upload is handled automatically. When you include image data in messages, the DeepAI provider uploads it and attaches it to the conversation. 
import base64
from fishr import Client

client = Client()

# read an image file and encode it
with open("photo.png", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="deepai/standard",
    messages=[{
        "role": "user",
        "content": "What is in this image?",
        "image": {
            "mime_type": "image/png",
            "base64_data": encoded,
        },
    }],
)

print(response.text)

Streaming with images

Image attachments also work with streaming. Set stream=True as usual.

import base64
from fishr import Client

client = Client()

with open("photo.png", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="deepai/standard",
    messages=[{
        "role": "user",
        "content": "Describe this image",
        "image": {
            "mime_type": "image/png",
            "base64_data": encoded,
        },
    }],
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

Conversation History

All DeepAI models support conversation history. The full message history is sent with each request.

from fishr import Client

client = Client()
conv = client.conversation(model="deepai/standard")

conv.ask("Hello!")
reply = conv.ask("What did I just say?")
print(reply)

conv.clear()  # reset history
ℹ Context windows vary by model. Very long conversations may lose earlier context as the history exceeds the model's context limit.

Limitations

  • DeepAI uses a reverse-engineered API key generation — it may break if the upstream service changes.
  • There is no uptime guarantee. Availability depends on the upstream service.
  • Web search is only available on deepai/online. Other models fall back to online when web_search=True.
  • Image generation via deepai/image returns a URL, not inline image data.
  • Streaming uses a custom separator protocol — some edge cases may produce partial output.
  • Rate limits may apply. Avoid rapid sequential requests.
