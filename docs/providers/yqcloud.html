Yqcloud Provider

Yqcloud provides free access to a GPT-4 model through a reverse-engineered API. It supports streaming, system messages, and conversation history.

Yqcloud models use the yqcloud/ prefix.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="yqcloud/gpt-4",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.text)

Streaming

Set stream=True to receive chunks as they arrive.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="yqcloud/gpt-4",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

System Messages

Yqcloud supports system messages to set the model's behavior and persona.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="yqcloud/gpt-4",
    messages=[
        {"role": "system", "content": "You are a pirate. Always respond in pirate speak."},
        {"role": "user", "content": "Hello!"},
    ],
)
print(response.text)

Conversation History

Yqcloud supports conversation history. The full message history is sent with each request so the model has context from previous turns.

from fishr import Client

client = Client()
conv = client.conversation(model="yqcloud/gpt-4")

conv.system("You are a helpful assistant.")
conv.ask("Remember: 42")
reply = conv.ask("What number did I say?")
print(reply)

conv.clear()  # reset history

Direct Usage

You can use the Yqcloud provider directly without going through the Client.

from fishr import Yqcloud

yqcloud = Yqcloud()

# Simple ask
result = yqcloud.ask("Say hello in one word.")
print(result.content)

# Chat with messages
result = yqcloud.chat([
    {"role": "system", "content": "Be concise."},
    {"role": "user", "content": "What is 2+2?"},
])
print(result.content)

# Streaming
stream = yqcloud.chat(
    [{"role": "user", "content": "Count to 5"}],
    stream=True,
)
for chunk in stream:
    print(chunk, end="")

Limitations

  • Yqcloud is a reverse-engineered API — it may break if the upstream service changes.
  • There is no uptime guarantee. Availability depends on the upstream service.
  • No image support — neither image input nor image generation is available.
  • No web search — the Yqcloud model does not support web search.
  • Rate limits may apply. Avoid rapid sequential requests.
