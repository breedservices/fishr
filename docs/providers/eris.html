Eris Provider

Eris provides free access to DeepSeek models via the FreeAI API. It supports streaming, system messages, conversation history, and a thinking mode that surfaces the model's reasoning process. Two models are available: Flash (fast, efficient) and Pro (more capable).

Eris models use the eris/ prefix.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="eris/deepseek-v4-flash",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.text)

Streaming

Set stream=True to receive chunks as they arrive.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="eris/deepseek-v4-flash",
    messages=[{"role": "user", "content": "Count from 1 to 5"}],
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

Think Harder

Eris supports a thinking mode via think_harder=True that enables the model's reasoning process. When streaming, reasoning tokens appear in chunk.choices[0].delta.thinking.

from fishr import Client

client = Client()

# Non-streaming — reasoning is included in the response
response = client.chat.completions.create(
    model="eris/deepseek-v4-flash",
    messages=[{"role": "user", "content": "What is 17 * 23?"}],
    think_harder=True,
)
print(response.text)

Streaming with thinking

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="eris/deepseek-v4-flash",
    messages=[{"role": "user", "content": "What is 17 * 23?"}],
    stream=True,
    think_harder=True,
)

for chunk in response:
    if chunk.choices[0].delta.thinking:
        print(chunk.choices[0].delta.thinking, end="", flush=True)
    elif chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
ℹ Eris and Opera Aria. The think_harder parameter is supported by both Eris and Opera Aria providers. On Eris, it enables DeepSeek's native reasoning mode. On Opera Aria, it prompts more deliberate responses.

System Messages

Eris supports system messages to set the model's behavior and persona.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="eris/deepseek-v4-flash",
    messages=[
        {"role": "system", "content": "You are a pirate. Always respond in pirate speak."},
        {"role": "user", "content": "Say hello."},
    ],
)
print(response.text)

Conversation History

Eris supports conversation history. The full message history is sent with each request so the model has context from previous turns.

from fishr import Client

client = Client()
conv = client.conversation(model="eris/deepseek-v4-flash")

conv.system("You are a helpful assistant. Be brief.")
conv.ask("Remember the number 55.")
reply = conv.ask("What number did I tell you to remember?")
print(reply)

conv.clear()  # reset history
ℹ Context windows vary by model. Very long conversations may lose earlier context as the history exceeds the model's context limit. Use conv.clear() to reset when needed.

Direct Usage

You can use the Eris provider directly without going through the Client.

from fishr import Eris

eris = Eris()

# Simple ask
result = eris.ask("Say hello in one word.")
print(result.content)

# Chat with messages
result = eris.chat([
    {"role": "system", "content": "Be concise."},
    {"role": "user", "content": "What is 2+2?"},
])
print(result.content)

# Streaming
stream = eris.chat(
    [{"role": "user", "content": "Count to 5"}],
    stream=True,
)
for chunk in stream:
    if isinstance(chunk, tuple):
        content, is_thinking = chunk
        if is_thinking:
            print(f"[think] {content}", end="")
        else:
            print(content, end="")
    else:
        print(chunk, end="")

With thinking enabled

from fishr import Eris

eris = Eris()

# Enable reasoning mode
result = eris.ask("Explain quantum entanglement.", enable_thinking=True)
print(result.content)

Limitations

  • Eris uses a reverse-engineered API — it may break if the upstream service changes.
  • There is no uptime guarantee. Availability depends on the upstream service.
  • No web search — Eris does not support live web search.
  • No image input — Eris does not support image attachments or image generation.
  • Rate limits may apply. Avoid rapid sequential requests.
  • Five models are currently available: eris/deepseek-v4-flash, eris/deepseek-v4-pro, eris/glm-5.1, eris/minimax-m3, and eris/kimi-k2.6.
