fishr

Free LLM access from Python. No keys. No cost. No limits.

uv add fishr

Installation

uv add fishr

Requires Python 3.11+. On Linux/macOS, uvloop is automatically installed for better async performance.

Quickstart

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="noxus/openai",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.text)

The provider/ prefix is optional — "openai" resolves to "noxus/openai".

Streaming

Set stream=True to receive chunks as they arrive. Works with all providers. 

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="noxus/openai",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

Web Search

Pass web_search=True to enable live web search on supported models. 

from fishr import Client

client = Client()

# Noxus
response = client.chat.completions.create(
    model="noxus/grok-4.3",
    messages=[{"role": "user", "content": "Latest news on SpaceX"}],
    web_search=True,
)
print(response.text)

# DeepAI (uses deepai/online automatically)
response = client.chat.completions.create(
    model="deepai/standard",
    messages=[{"role": "user", "content": "Latest news on SpaceX"}],
    web_search=True,
)
print(response.text)

# Quillbot
response = client.chat.completions.create(
    model="quillbot/quillbot",
    messages=[{"role": "user", "content": "Latest news on SpaceX"}],
    web_search=True,
)
print(response.text)
⚠ Web search is not supported by all models. Noxus has 6 search-capable models, DeepAI routes to deepai/online, Quillbot enables it via quillbot-search, and NoTrack does not support web search at all.

Image Generation

Use client.images.generate() to generate images from text prompts. Two providers are available:

  • DeepAI (deepai/image) — text-to-image via DeepAI's text2img API.
  • Raphael (raphael/image) — text-to-image and image-to-image via raphael.app, with configurable aspect ratio, resolution, and quality.

DeepAI

from fishr import Client

client = Client()

result = client.images.generate(
    model="deepai/image",
    prompt="A cat riding a skateboard on Mars",
)

# the generated image URL
print(result.data[0].url)
print(result.data[0].alt)  # the prompt used

Raphael (text-to-image)

from fishr import Client

client = Client()

result = client.images.generate(
    model="raphael/image",
    prompt="A serene mountain lake at sunset",
    number_of_images=2,
    aspect="1:1",
    resolution="0.5k",
    quality="low",
)

for img in result.data:
    print(img.url)

Raphael (image-to-image / img2img)

Pass an image dict to transform an existing image. Supported MIME types: image/webp, image/png, image/jpeg, image/jpg. 

import base64
from fishr import Client

client = Client()

with open("input.webp", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

result = client.images.generate(
    model="raphael/image",
    prompt="Make it to be black & red",
    image={
        "mime_type": "image/webp",
        "base64_data": encoded,
    },
    aspect="auto",
    resolution="1k",
)

print(result.data[0].url)

Async

from fishr import AsyncClient

client = AsyncClient()

result = await client.images.generate(
    model="raphael/image",
    prompt="A futuristic city at sunset",
)
print(result.data[0].url)
ℹ Image generation is available via deepai/image and raphael/image. DeepAI returns a single image URL. Raphael can return multiple images and supports img2img. See the DeepAI and Raphael provider docs for details.

Via completions API

You can also use deepai/image through the completions API. The response text will contain the generated image URL. (Raphael is only available via client.images.generate().) 

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="deepai/image",
    messages=[{"role": "user", "content": "A cat riding a skateboard"}],
)
print(response.text)  # image URL

Image Input

Some models accept image attachments. Pass a base64-encoded image in the image key of a message with mime_type and base64_data.

ℹ Image input works with both Noxus and DeepAI. Noxus sends images directly with the message. DeepAI uploads them to its attachment API and references them by UUID. See the Noxus and DeepAI provider docs for details. For image-to-image generation (img2img), use Raphael with the image parameter on client.images.generate().

Noxus image input

import base64
from fishr import Client

client = Client()

# read an image file and encode it
with open("photo.png", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="noxus/openai",
    messages=[{
        "role": "user",
        "content": "What is in this image?",
        "image": {
            "mime_type": "image/png",
            "base64_data": encoded,
        },
    }],
)

print(response.text)

DeepAI image upload

DeepAI chat models also support image attachments. The image is automatically uploaded and attached to the conversation. 

import base64
from fishr import Client

client = Client()

with open("photo.png", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="deepai/standard",
    messages=[{
        "role": "user",
        "content": "What is in this image?",
        "image": {
            "mime_type": "image/png",
            "base64_data": encoded,
        },
    }],
)

print(response.text)
⚠ Image input is not supported by all models. See Noxus and DeepAI docs for supported models. Quillbot and NoTrack do not support image input. Models marked ❌ will ignore attached images.

Audio Generation

Use client.audio.speech.create(...) to generate speech from text. fishr supports three TTS providers: fm (OpenAI.fm), telnyx-tts (Telnyx NaturalHD via the no-auth fast-path demo), and make (Qwen3 TTS, 39 voices). All mirror the OpenAI text-to-speech API and return raw audio bytes in result.data[0].audio. 

from fishr import Client

client = Client()

# OpenAI.fm
result = client.audio.speech.create(
    model="fm/coral",
    input="Hello from fishr.",
)

# Telnyx TTS (no-auth fast-path)
result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Hello from Telnyx.",
)

# Make (Qwen3 TTS, 39 voices)
result = client.audio.speech.create(
    model="make/aura",
    input="Hello from Make.",
)

# result.data[0].audio is raw audio bytes (MP3 for fm/telnyx-tts, WAV for make)
# use format="mp3" to transcode make's WAV to MP3
with open("out.wav", "wb") as fh:
    fh.write(result.data[0].audio)

fm — voices & styles

FM offers 11 voices and 6 preset styles. Voices (e.g. fm/coral) only select the voice. Styles (e.g. fm/cowboy) fill in instructions for you and use the default voice unless you override voice=.... 

from fishr import Client

client = Client()

# explicit voice
result = client.audio.speech.create(
    model="fm/coral",
    input="Hello from nova.",
    voice="nova",
)

# style model (instructions come from the style)
result = client.audio.speech.create(
    model="fm/noir_detective",
    input="The package went missing at midnight.",
)

# custom instructions
result = client.audio.speech.create(
    model="fm/coral",
    input="Hello world.",
    instructions="Speak softly and slowly.",
)

telnyx-tts — voice-as-model

Telnyx TTS exposes five NaturalHD voices. Each model id is a voice — there is no separate style layer. You can still override the voice on top of any model with voice=.... Voices: telnyx-tts/astra (default), telnyx-tts/luna, telnyx-tts/sol, telnyx-tts/nova, telnyx-tts/orion. 

from fishr import Client

client = Client()

# default voice (astra)
result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Hello from astra.",
)

# different voice via model
result = client.audio.speech.create(
    model="telnyx-tts/luna",
    input="Hello from luna.",
)

# override the voice on top of any model
result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Hello from orion via override.",
    voice="orion",
)

# explicit BCP-47 language (defaults to en-US)
result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Bonjour.",
    voice="astra",
)

make — 39 voices

Make offers 39 Qwen3 TTS voices named after natural elements and textures: make/aura (default), make/breeze, make/cypress, ... make/willow. Each model id is a voice. Make emits WAV by default — use format=... to transcode. 

from fishr import Client

client = Client()

# default voice (aura)
result = client.audio.speech.create(
    model="make/aura",
    input="Hello from aura.",
)

# different voice via model
result = client.audio.speech.create(
    model="make/breeze",
    input="Hello from breeze.",
)

# transcode WAV to MP3
result = client.audio.speech.create(
    model="make/mist",
    input="Transcode me.",
    format="mp3",
)

Formats & transcoding

fm and telnyx-tts emit MP3; make emits WAV. Pass format=... to transcode to other formats using the bundled static-ffmpeg binary — no system ffmpeg install needed. Supported formats: mp3, ogg, wav, flac, opus, aac, m4a. 

from fishr import Client

client = Client()

result = client.audio.speech.create(
    model="telnyx-tts/astra",
    input="Transcode me to WAV.",
    format="wav",
)
print(result.data[0].mime_type)  # audio/wav

from fishr import AsyncClient

client = AsyncClient()

result = await client.audio.speech.create(

    input="Hello from the async high level client.",

Direct usage

You can also use any provider directly without the Client wrapper. The low-level speak() methods return raw audio bytes — use the high-level client if you need format= transcoding. 

from fishr import OpenAIFM, TelnyxAudio, MusicMake

fm = OpenAIFM()
result = fm.speak("Hello world.")
print(result.voice, len(result.audio))

ta = TelnyxAudio()
result = ta.speak("Hello from Telnyx.", model="telnyx-tts/luna")
print(result.model, result.voice, len(result.audio))

mm = MusicMake()
result = mm.speak("Hello from Make.", model="make/aura")
print(result.voice, len(result.audio))
ℹ See the provider pages for full details: FM (OpenAI.fm) · Telnyx TTS · Make.

Agents

Use client.agents.run() to run a multi-step agent loop. The agent iteratively calls the LLM with tool results until it produces a final answer or reaches the step limit. 

from fishr import Client

client = Client()

result = client.agents.run(
    model="noxus/openai",
    instructions="You are a helpful research assistant.",
    prompt="What are the latest developments in quantum computing?",
    tools=[{"type": "web_search"}],
    max_steps=5,
)

print(result.content)

Async

from fishr import AsyncClient

client = AsyncClient()

result = await client.agents.run(
    model="noxus/grok-4.3",
    instructions="You are a helpful research assistant.",
    prompt="What are the latest developments in quantum computing?",
    tools=[{"type": "web_search"}],
    max_steps=5,
)

print(result.content)

AgentStep

Field Type Description
role str Always "assistant"
content str Final response text
tool str Tool name if a tool was called
tool_input str Tool input if a tool was called

Tool Calling

The kai/* provider is the only fishr provider with native OpenAI-style tool calling. Pass tools (a list of OpenAI tool definitions) and the model returns structured tool_calls on the assistant message. 

from fishr import Client

client = Client()

tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "Get current weather for a location",
        "parameters": {
            "type": "object",
            "properties": {"location": {"type": "string"}},
            "required": ["location"],
        },
    },
}]

resp = client.chat.completions.create(
    model="kai/auto",
    messages=[{"role": "user", "content": "What's the weather in Tokyo?"}],
    tools=tools,
)

for tc in resp.choices[0].message.tool_calls:
    print(tc.function.name, tc.function.arguments)
# get_weather {"location": "Tokyo"}

Use tool_choice to steer tool selection: "auto" (default), "none", "required", or {"type": "function", "function": {"name": "..."}} to force a specific function.

ℹ See the Kai provider page for multi-turn tool use, streaming tool calls, and direct usage.

Think Harder

Use think_harder=True with Eris or Opera Aria to enable reasoning mode. When streaming, reasoning tokens appear in chunk.choices[0].delta.thinking. 

from fishr import Client

client = Client()

# Eris — DeepSeek thinking mode
response = client.chat.completions.create(
    model="eris/deepseek-v4-flash",
    messages=[{"role": "user", "content": "What is 17 * 23?"}],
    think_harder=True,
)
print(response.text)

# Opera Aria
response = client.chat.completions.create(
    model="opera/aria",
    messages=[{"role": "user", "content": "What is 17 * 23?"}],
    think_harder=True,
)
print(response.text)

Streaming with thinking

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="eris/deepseek-v4-flash",
    messages=[{"role": "user", "content": "Solve: 17 * 23"}],
    stream=True,
    think_harder=True,
)

for chunk in response:
    if chunk.choices[0].delta.thinking:
        print(chunk.choices[0].delta.thinking, end="")
    elif chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")

Async

Use AsyncClient for non-blocking calls.

import asyncio
from fishr import AsyncClient

async def main():
    client = AsyncClient()

    response = await client.chat.completions.create(
        model="noxus/openai",
        messages=[{"role": "user", "content": "Hello!"}],
    )
    print(response.text)

    # streaming
    response = await client.chat.completions.create(
        model="noxus/openai",
        messages=[{"role": "user", "content": "Tell me a story"}],
        stream=True,
    )
    async for chunk in response:
        print(chunk.choices[0].delta.content or "", end="")

asyncio.run(main())

Multi-turn Conversation

Conversations maintain history automatically. Works with all providers — Noxus, DeepAI, Quillbot, NoTrack, DphnAI, Opera Aria, and Eris.

Sync

from fishr import Client

client = Client()

# noxus
conv = client.conversation(model="noxus/openai")
conv.system("You are a helpful assistant.")
conv.ask("Remember: 42")
reply = conv.ask("What number did I say?")
print(reply)  # "You said 42."

# deepai
conv = client.conversation(model="deepai/standard")
conv.ask("Hello!")

# quillbot
conv = client.conversation(model="quillbot/quillbot")
conv.system("You are a helpful assistant.")
conv.ask("Remember: 42")

# notrack
conv = client.conversation(model="notrack/standard")
conv.ask("Hello!")

# dphnai
conv = client.conversation(model="dphnai/6b")
conv.ask("Hello!")

# eris
conv = client.conversation(model="eris/deepseek-v4-flash")
conv.ask("Hello!")

conv.clear()  # reset history

Async

from fishr import AsyncClient

client = AsyncClient()
conv = client.conversation(model="noxus/openai")

await conv.ask("Remember: 42")
reply = await conv.ask("What number did I say?")
print(reply)

Methods

Method Description
ask(prompt, **kwargs) Send a message and return the response
system(content) Add a system message to history
clear() Reset conversation history
len(conv) Number of messages in history

Built-in Chat UI

fishr ships with a built-in web chat UI for testing models interactively. It's a single-page app served from fishr.chat that streams responses over SSE, with no separate frontend build step. 

from fishr.chat import Run

Run(host="127.0.0.1", port=8000)

Then open http://127.0.0.1:8000 in your browser.

Features

  • Model selector — grouped by provider prefix (e.g. noxus/, eris/).
  • Streaming — responses stream token-by-token over SSE.
  • Thinking blocks — collapsible reasoning output for Eris and Opera Aria when Think Harder is on.
  • Web search toggle for models that support it.
  • Image generation for DeepAI and Opera Aria models.
  • File attachments for vision-capable models.
  • System prompts — optional per-conversation.
  • Markdown rendering with syntax highlighting (highlight.js) and inline image URLs.
  • Multi-provider Compare — send the same prompt to 2–4 models at once and view responses side-by-side.

Compare Mode

Toggle Compare in the header to switch into comparison mode. Pick 2–4 models from the dropdowns (use the 2→3→4 button to cycle the column count), type one prompt, and hit send. A full-screen grid opens with each model streaming into its own panel. Per-panel status indicators (⏳ ✍️ ❌ ✅) track each stream.

ℹ How it works. The UI POSTs the prompt to /api/chat/compare, which runs each model concurrently on the server via asyncio.gather and multiplexes their chunks into a single SSE stream tagged with a panel index. No browser-side concurrency limits are hit because it's one HTTP connection.

HTTP Endpoints

Method Path Description
GET / Serves the single-page chat UI (ui.html)
GET /api/models Lists all registered models from fishr.Types.models
POST /api/chat Stream a single-model completion (SSE)
POST /api/chat/compare Stream 2–4 models concurrently into one multiplexed SSE stream
POST /api/images Generate an image (DeepAI or Opera Aria)
POST /api/audio Generate speech via FM (returns raw audio bytes)

Compare Request Body

{
  "models": ["noxus/openai", "eris/deepseek-v4-flash", "opera/aria"],
  "messages": [{"role": "user", "content": "Hello!"}],
  "web_search": false,
  "think_harder": false
}

Each SSE data: frame is tagged with idx (the panel index) and a type of thinking, content, error, or done. The stream closes with data: [DONE] once all models finish.

client.chat.completions.create()

model str required

Model name in provider/name format, e.g. "noxus/openai", "deepai/standard", "quillbot/quillbot", "notrack/fast", "dphnai/6b". Noxus prefix is optional.

messages list[dict] required

List of {"role": ..., "content": ...} dicts. Some providers support "image" with {"mime_type": ..., "base64_data": ...} — see Image Input.

web_search bool default: False

Enable web search for supported models.

stream bool default: False

Return an iterator of ChatCompletionChunk instead of a single ChatCompletion.

think_harder bool default: False

Enable reasoning mode for Eris and Opera Aria models. When streaming, reasoning tokens appear in chunk.choices[0].delta.thinking.

tools list[dict] | None default: None

OpenAI-style tool definitions. Kai only — the only provider with native tool calling. Other providers silently ignore this.

tool_choice str | dict | None default: None

Tool selection strategy: "auto", "none", "required", or {"type": "function", "function": {"name": "..."}}. Kai only.

max_tokens int | None default: None

Maximum tokens to generate. Forwarded to Kai and Telnyx; silently ignored by other providers. Telnyx defaults to the model's context cap (kimi=224K, glm-5.2=968K, glm-5.1=168K, minimax=168K); Kai defaults to 16384.

temperature float | None default: None

Sampling temperature (0–2). Kai only. Other providers silently ignore this.

client.images.generate()

model str default: "deepai/image"

Image generation model. deepai/image uses DeepAI's text2img API. raphael/image uses raphael.app (supports text-to-image and image-to-image via the image parameter).

prompt str required

Text prompt describing the image to generate.

number_of_images int default: 1

Number of images to generate. Raphael only. Ignored by DeepAI.

aspect str default: "1:1"

Aspect ratio. Raphael only. One of 1:1, 4:3, 3:4, 16:9, 9:16, auto.

resolution str default: "0.5k"

Resolution. Raphael only. One of 0.5k, 1k, 2k.

quality str default: "low"

Quality. Raphael only. One of low, medium, high.

fast_mode bool default: False

Fast generation mode. Raphael only.

high_quality bool default: False

Request high-quality output. Raphael only.

image dict | None default: None

Reference image for image-to-image (img2img). Raphael only. Dict with mime_type (image/webp, image/png, image/jpeg, image/jpg) and base64_data.

Returns an ImageResponse with data containing ImageUrl objects (one per generated image). data[i].url is the image URL, data[i].alt is the prompt.

client.audio.speech.create()

model str default: "fm/coral"

Audio model. fm/* routes to OpenAI.fm (voice or style). telnyx-tts/* routes to the Telnyx no-auth fast-path demo — each model id is a voice (e.g. telnyx-tts/astra, telnyx-tts/luna, telnyx-tts/sol, telnyx-tts/nova, telnyx-tts/orion).

input str required

Text to synthesize.

voice str | None default: None

Override the voice. For fm/*, falls back to the voice resolved from model (or coral for a style). For telnyx-tts/*, falls back to the voice embedded in the model id.

instructions str | None default: None

Steer how the voice speaks (tone, pacing, emotion). fm/* only — ignored by telnyx-tts/*. Falls back to the style's preset instructions when model is a style.

format str | None default: None

Output container: mp3, ogg, wav, flac, opus, aac, m4a. If omitted, the provider's native format is used (MP3 for fm/* and telnyx-tts/*, WAV for make/*). Any other format is transcoded via the bundled static-ffmpeg binary — no system ffmpeg needed. Applies to all three TTS providers.

Returns an AudioResponse with data[0].audio containing the raw audio bytes and data[0].mime_type the MIME type.

client.agents.run()

model str default: "noxus/openai"

Model to use for the agent. Supports Noxus and DeepAI providers.

instructions str default: ""

System instructions for the agent.

prompt str required

The user prompt to start the agent loop.

tools list[dict] | None default: None

List of tools the agent can use. Currently supports {"type": "web_search"}.

max_steps int default: 5

Maximum number of agent iterations before returning.

Returns an AgentStep with the final response in content.

client.conversation()

model str default: "noxus/openai"

Model to use for the conversation. Works with all providers — Noxus, DeepAI, Quillbot, NoTrack, and DphnAI.

Returns a Conversation (sync) or AsyncConversation (async) instance.
