fishr

Free LLM access from Python. No keys. No cost. No limits.

uv add fishr

Installation

uv add fishr

Requires Python 3.11+. On Linux/macOS, uvloop is automatically installed for better async performance.

Quickstart

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="noxus/openai",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.text)

Providers

Models are specified as provider/name. Each provider offers different models and capabilities.

The provider/ prefix is optional — "openai" resolves to "noxus/openai".

noxus

8 models — GPT, Gemini, Sonnet, Grok, Perplexity, Llama, Qwen

Web Search Images Streaming

deepai

6 models — Standard, Online, Gemma 4, Gemini Flash, DeepSeek, Image Gen

Web Search Image Gen Streaming

quillbot

2 models — Standard Chat, Web Search

Web Search Streaming

notrack

3 models — Fast, Standard, Reasoning

Streaming

dphnai

2 models — Dolphin 24B, Dolphin 6B (with templates)

Streaming

yqcloud

1 model — GPT-4 chat

Streaming

opera

1 model — Aria (image generation supported)

Image Gen Streaming
⚠ Not all models support every feature. Check the provider pages for details on which models support web search, image input, and image generation.

Chat Completions

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="noxus/openai",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is Python?"},
    ],
)

print(response.text)
# or: print(response.choices[0].message.content)

Streaming

Set stream=True to receive chunks as they arrive. Works with all providers.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="noxus/openai",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

Web Search

Pass web_search=True to enable live web search on supported models.

from fishr import Client

client = Client()

# Noxus
response = client.chat.completions.create(
    model="noxus/grok-4.3",
    messages=[{"role": "user", "content": "Latest news on SpaceX"}],
    web_search=True,
)
print(response.text)

# DeepAI (uses deepai/online automatically)
response = client.chat.completions.create(
    model="deepai/standard",
    messages=[{"role": "user", "content": "Latest news on SpaceX"}],
    web_search=True,
)
print(response.text)

# Quillbot
response = client.chat.completions.create(
    model="quillbot/quillbot",
    messages=[{"role": "user", "content": "Latest news on SpaceX"}],
    web_search=True,
)
print(response.text)
⚠ Web search is not supported by all models. Noxus has 6 search-capable models, DeepAI routes to deepai/online, Quillbot enables it via quillbot-search, and NoTrack does not support web search at all.

Image Generation

Use client.images.generate() to generate images from text prompts. This uses DeepAI's text2img API.

from fishr import Client

client = Client()

result = client.images.generate(
    model="deepai/image",
    prompt="A cat riding a skateboard on Mars",
)

# the generated image URL
print(result.data[0].url)
print(result.data[0].alt)  # the prompt used

Async

from fishr import AsyncClient

client = AsyncClient()

result = await client.images.generate(
    model="deepai/image",
    prompt="A futuristic city at sunset",
)
print(result.data[0].url)
ℹ Image generation is only available via deepai/image. Other DeepAI chat models can trigger inline image generation during conversation via the built-in image generator tool, but client.images.generate() is the recommended approach.

Via completions API

You can also use deepai/image through the completions API. The response text will contain the generated image URL.

from fishr import Client

client = Client()

response = client.chat.completions.create(
    model="deepai/image",
    messages=[{"role": "user", "content": "A cat riding a skateboard"}],
)
print(response.text)  # image URL

Image Input

Some models accept image attachments. Pass a base64-encoded image in the image key of a message with mime_type and base64_data.

ℹ Image input works with both Noxus and DeepAI. Noxus sends images directly with the message. DeepAI uploads them to its attachment API and references them by UUID. See the Noxus and DeepAI provider docs for details.

Noxus image input

import base64
from fishr import Client

client = Client()

# read an image file and encode it
with open("photo.png", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="noxus/openai",
    messages=[{
        "role": "user",
        "content": "What is in this image?",
        "image": {
            "mime_type": "image/png",
            "base64_data": encoded,
        },
    }],
)

print(response.text)

DeepAI image upload

DeepAI chat models also support image attachments. The image is automatically uploaded and attached to the conversation.

import base64
from fishr import Client

client = Client()

with open("photo.png", "rb") as f:
    encoded = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="deepai/standard",
    messages=[{
        "role": "user",
        "content": "What is in this image?",
        "image": {
            "mime_type": "image/png",
            "base64_data": encoded,
        },
    }],
)

print(response.text)
⚠ Image input is not supported by all models. See Noxus and DeepAI docs for supported models. Quillbot and NoTrack do not support image input. Models marked ❌ will ignore attached images.

Agents

Use client.agents.run() to run a multi-step agent loop. The agent iteratively calls the LLM with tool results until it produces a final answer or reaches the step limit.

from fishr import Client

client = Client()

result = client.agents.run(
    model="noxus/openai",
    instructions="You are a helpful research assistant.",
    prompt="What are the latest developments in quantum computing?",
    tools=[{"type": "web_search"}],
    max_steps=5,
)

print(result.content)

Async

from fishr import AsyncClient

client = AsyncClient()

result = await client.agents.run(
    model="noxus/grok-4.3",
    instructions="You are a helpful research assistant.",
    prompt="What are the latest developments in quantum computing?",
    tools=[{"type": "web_search"}],
    max_steps=5,
)

print(result.content)

Async

Use AsyncClient for non-blocking calls.

import asyncio
from fishr import AsyncClient

async def main():
    client = AsyncClient()

    response = await client.chat.completions.create(
        model="noxus/openai",
        messages=[{"role": "user", "content": "Hello!"}],
    )
    print(response.text)

    # streaming
    response = await client.chat.completions.create(
        model="noxus/openai",
        messages=[{"role": "user", "content": "Tell me a story"}],
        stream=True,
    )
    async for chunk in response:
        print(chunk.choices[0].delta.content or "", end="")

asyncio.run(main())

Multi-turn Conversation

Conversations maintain history automatically. Works with all providers — Noxus, DeepAI, Quillbot, NoTrack, and DphnAI.

Sync

from fishr import Client

client = Client()

# noxus
conv = client.conversation(model="noxus/openai")
conv.system("You are a helpful assistant.")
conv.ask("Remember: 42")
reply = conv.ask("What number did I say?")
print(reply)  # "You said 42."

# deepai
conv = client.conversation(model="deepai/standard")
conv.ask("Hello!")

# quillbot
conv = client.conversation(model="quillbot/quillbot")
conv.system("You are a helpful assistant.")
conv.ask("Remember: 42")

# notrack
conv = client.conversation(model="notrack/standard")
conv.ask("Hello!")

# dphnai
conv = client.conversation(model="dphnai/6b")
conv.ask("Hello!")

conv.clear()  # reset history

Async

from fishr import AsyncClient

client = AsyncClient()
conv = client.conversation(model="noxus/openai")

await conv.ask("Remember: 42")
reply = await conv.ask("What number did I say?")
print(reply)

API Reference

Client

Client()

Creates a synchronous fishr client.

AsyncClient

AsyncClient()

Creates an asynchronous fishr client. All .create() and .generate() calls must be awaited.

client.chat.completions.create()

model str required

Model name in provider/name format, e.g. "noxus/openai", "deepai/standard", "quillbot/quillbot", "notrack/fast", "dphnai/6b". Noxus prefix is optional.

messages list[dict] required

List of {"role": ..., "content": ...} dicts. Some providers support "image" with {"mime_type": ..., "base64_data": ...} — see Image Input.

web_search bool default: False

Enable web search for supported models.

stream bool default: False

Return an iterator of ChatCompletionChunk instead of a single ChatCompletion.

client.images.generate()

model str default: "deepai/image"

Image generation model. Currently only deepai/image is supported.

prompt str required

Text prompt describing the image to generate.

Returns an ImageResponse with data[0].url containing the generated image URL.

client.agents.run()

model str default: "noxus/openai"

Model to use for the agent. Supports Noxus and DeepAI providers.

instructions str default: ""

System instructions for the agent.

prompt str required

The user prompt to start the agent loop.

tools list[dict] | None default: None

List of tools the agent can use. Currently supports {"type": "web_search"}.

max_steps int default: 5

Maximum number of agent iterations before returning.

Returns an AgentStep with the final response in content.

client.conversation()

model str default: "noxus/openai"

Model to use for the conversation. Works with all providers — Noxus, DeepAI, Quillbot, NoTrack, and DphnAI.

Returns a Conversation (sync) or AsyncConversation (async) instance.
